# Тренинг «СПИН-продажи» — презентация (70 слайдов)

Полноценная 2-дневная программа тренинга по методике SPIN Selling (Нил Рэкхем):
теория, банки вопросов по каждому типу (S/P/I/N), разборы диалогов, техника
работы с возражениями, получение обязательств, ролевые игры и план внедрения.

## Как открыть

Просто откройте `index.html` в любом браузере (Chrome, Safari, Edge).
Интернет не нужен — файл полностью самодостаточный.

## Управление

| Действие | Клавиша |
|---|---|
| Следующий слайд | `→`, `Пробел`, `PageDown` |
| Предыдущий слайд | `←`, `PageUp` |
| В начало / в конец | `Home` / `End` |
| Полноэкранный режим (для проектора) | `F` |
| Печать / сохранить в PDF | `P` |

Кнопки «Назад/Вперёд» и счётчик слайдов есть внизу экрана.
Номер слайда сохраняется в адресной строке (`index.html#42`) — можно
делиться ссылкой на конкретный слайд.

## Экспорт

- **В PDF (раздатка участникам):** откройте презентацию → нажмите `P` →
  в диалоге печати выберите «Сохранить как PDF», ориентация — альбомная.
- **В PowerPoint:** сначала сохраните в PDF (см. выше), затем импортируйте
  PDF в PowerPoint/Keynote, либо используйте любой конвертер PDF→PPTX.

## Структура (11 модулей)

1. Почему классические техники не работают в крупных продажах
2. Модель СПИН и логика воронки вопросов
3. Ситуационные вопросы (S)
4. Проблемные вопросы (P)
5. Извлекающие вопросы (I) — ядро метода
6. Направляющие вопросы (N)
7. Характеристики → Преимущества → Выгоды (ХПВ / FAB)
8. Работа с возражениями
9. Получение обязательств
10. Подготовка к встрече (чек-листы и матрица вопросов)
11. Ролевые игры + план внедрения 30/60/90

Каждый содержательный блок построен по схеме:
**объяснение → примеры → банк вопросов → упражнение → разбор.**

## Как проводить тренинг

- Формат: 2 дня, ~30% теории / 70% практики.
- 5 упражнений и 2 ролевые игры встроены в слайды (ищите плашки «Упражнение»
  и «Ролевая игра»).
- Для каждого упражнения участники работают на **своём** продукте и реальных
  клиентах — к концу тренинга у них готов рабочий банк вопросов S-P-I-N.
- Слайд 67 — «Шпаргалка на одну страницу», её удобно распечатать и раздать.
